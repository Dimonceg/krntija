# Krntija

Роуд-трип-выживалка про ржавую машину, балканскую дорогу и 90-е.
Godot 4.7 (.NET) + симуляционное ядро на C#, которое живёт отдельно от движка.

> **Статус:** одиночная игра собрана (езда, поломки, лут, карта, дом-база),
> идёт полировка перед плейтестом. Подробно — `docs/ROADMAP.md`.

## Почему так

`core/` — чистая C#-библиотека без единой ссылки на Godot: детали, износ, топливо,
температура, потребности, инвентарь, время, сейвы. Всё это покрыто тестами и
крутится за миллисекунды. `game/` — только представление: рендер, ввод, звук, UI.

Из этого следуют три вещи, ради которых всё и затевалось:

1. Баланс можно править и проверять без запуска игры.
2. Сервер для кооп-режима — это тот же `core/` в headless-режиме, а не вторая игра.
3. Смена движка (если вдруг) стоит недели, а не годы.

## Структура

```
krntija/
├─ core/
│  ├─ Krntija.Core/          # симуляция, ноль зависимостей от движка
│  └─ Krntija.Core.Tests/    # xUnit
├─ game/                     # Godot-проект
│  ├─ scenes/
│  └─ scripts/               # Main.*.cs — partial-класс по темам
├─ docs/
│  ├─ HANDOFF.md             # с чего начать, команды, известные проблемы
│  ├─ ROADMAP.md             # этапы M0..M4
│  ├─ DEVLOG.md              # почему сделано именно так
│  └─ ADR/                   # решения и почему они такие
└─ tools/                    # скрипты сборки и проверок
```

## Быстрый старт

Одна команда — пересборка и запуск:

```powershell
powershell -ExecutionPolicy Bypass -File tools\play.ps1
```

Аргументы после имени скрипта уходят в игру:

```powershell
# на выбранной машине
powershell -ExecutionPolicy Bypass -File tools\play.ps1 --car=golf_2

# прогон-проверка, игра закроется сама
powershell -ExecutionPolicy Bypass -File tools\play.ps1 --smoke

# без пересборки / с повторным импортом ассетов
powershell -ExecutionPolicy Bypass -File tools\play.ps1 -NoBuild
powershell -ExecutionPolicy Bypass -File tools\play.ps1 -RebuildAssets
```

Остальные проверки:

```powershell
# всё перед слиянием: тесты, сборка, headless-проверки
powershell -ExecutionPolicy Bypass -File tools\check.ps1

# тесты ядра
powershell -ExecutionPolicy Bypass -File tools\test.ps1

# headless-прогон физики (код возврата 0 = ок)
powershell -ExecutionPolicy Bypass -File tools\smoke.ps1
```

Скрипты сами подставляют `DOTNET_ROOT=C:\Tools\dotnet` и путь к Godot —
машинный .NET 6 для Godot 4.7 не подходит, а трогать системные переменные мы не хотим.

## Управление

| Клавиша | Действие |
|---|---|
| W | газ |
| S | тормоз; на остановке — задний ход |
| A / D | руль (пешком — поворот) |
| V | зажигание |
| Space | ручник (пешком — бег) |
| E | выйти из машины / сесть / заправить / оплатить шлагбаум / войти в лавку |
| J | журнал: детали, инвентарь, задача |
| ↑ / ↓, T, R | в журнале: выбрать деталь, поставить из сумки, подмотать изолентой |
| 1..9 | в журнале — использовать предмет; в лавке — купить |
| S | в лавке — сдать деталь за половину цены |
| F5 / F9 | сохранить / загрузить |
| Esc | выход |

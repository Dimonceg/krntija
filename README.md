# Krntija

Роуд-трип-выживалка про ржавую машину, балканскую дорогу и 90-е.
Godot 4.7 (.NET) + симуляционное ядро на C#, которое живёт отдельно от движка.

> **Статус:** M0 — скелет проекта и прототип машины.

## Почему так

`core/` — чистая C#-библиотека без единой ссылки на Godot: детали, износ, топливо,
температура, потребности, инвентарь, время, сейвы. Всё это покрыто тестами и
крутится за миллисекунды. `game/` — только представление: рендер, ввод, звук, UI.

Из этого следуют три вещи, ради которых всё и затевалось:

1. Баланс можно править и проверять без запуска игры.
2. Сервер для кооп-режима — это тот же `core/` в headless-режиме, а не вторая игра.
3. Смена движка (если вдруг) стоит недели, а не годы.

## Структура

```
krntija/
├─ core/
│  ├─ Krntija.Core/          # симуляция, ноль зависимостей от движка
│  └─ Krntija.Core.Tests/    # xUnit
├─ game/                     # Godot-проект
│  ├─ scenes/
│  └─ scripts/
├─ docs/
│  ├─ GDD.md                 # что за игра
│  ├─ ROADMAP.md             # этапы M0..M4
│  └─ ADR/                   # решения и почему они такие
└─ tools/                    # скрипты сборки и проверок
```

## Быстрый старт

```powershell
# тесты ядра (23 теста, ~0.3 с)
powershell -ExecutionPolicy Bypass -File tools\test.ps1

# игра с окном
powershell -ExecutionPolicy Bypass -File tools\play.ps1

# headless-прогон физики (CI-проверка, что машина едет; код возврата 0 = ок)
powershell -ExecutionPolicy Bypass -File tools\smoke.ps1
```

Скрипты сами подставляют `DOTNET_ROOT=C:\Tools\dotnet` и путь к Godot —
машинный .NET 6 для Godot 4.7 не подходит, а трогать системные переменные мы не хотим.

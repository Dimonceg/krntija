# Задание: пыль не квадратами, а мягкими облачками

## Цель

Сейчас пыль из-под колёс выглядит как набор резких квадратов. Нужно, чтобы она
читалась как пыль: мягкие круглые пятна, которые появляются у колеса маленькими,
растут, мутнеют и растворяются, пока летят. Никаких файлов текстур — всё
процедурно, в коде.

## Что сделать

Правь `game/scripts/CarDust.cs` (заготовка уже собирается и работает, но пятна
квадратные). Меняй только то, что помечено `TODO`, и значения рядом:

1. **Мягкий край пятна** — `MakePuffTexture`, градиент альфы по кругу: в центре
   1.0, к краю 0.0. Сейчас оба конца белые и непрозрачные, поэтому край квадратный.
2. **Растворение по жизни** — `MakeFadeRamp` (`ColorRamp`): 0 → альфа 0.0,
   ~0.15 → 0.85, 1 → альфа 0.0. Цвет тёплый пыльный, например (0.85, 0.80, 0.70).
3. **Рост по жизни** — `MakeGrowCurve` (`ScaleCurve`): в начале 0.35, к концу 1.0
   (кривая из двух-трёх точек).
4. **Движение** — `ParticleProcessMaterial`: пыль идёт вверх и назад
   (`Direction` с положительным Z), разброс `Spread` 45–60°, скорости 0.4–1.4 м/с,
   гравитация чуть вверх, `ScaleMin/Max` 0.6–1.1.
5. **Плотность** — `Amount` 14–20, `Lifetime` 1.0–1.3, размер квада 0.5–0.7 м,
   альфа материала 0.5–0.7 (мягкое пятно можно сделать плотнее квадрата).

Не трогай `_Process` (логика включения и позиций уже верная) и не меняй
сигнатуры/поля — только тела трёх `Make...` методов и значения в `_Ready`.

## Проверка

- `dotnet build` без предупреждений;
- `--selftest` зелёный;
- снимок `--shot-drive` — на нём пыль должна быть мягкой, без резких углов.

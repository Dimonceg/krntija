# assets/

Сюда попадают только **CC0-ассеты или свои**. Всё остальное — даже «на посмотреть» —
в репозиторий не кладём. Подробности и лицензии — в [docs/ART.md](../../docs/ART.md).

```
assets/
├─ models/
│  ├─ cars/     <spec_id>.glb      — кузов без колёс (zastava_101, golf_2, vaz_2106, zaz_968)
│  └─ props/    <feature>.glb      — gasstation, village, ruins, farm, checkpoint
├─ textures/                       — тайлящиеся текстуры, 512–1024 px
└─ audio/                          — пусто: звук синтезируется кодом
```

## Как Godot видит файлы

- Формат моделей — **GLB** (glTF 2.0 с встроенными текстурами). Один файл, без
  зависимостей.
- После добавления файла нужно один раз открыть проект в редакторе Godot или
  запустить `godot --headless --path game --import`, чтобы появился `.import`.
- Файлы `.import` **коммитим** — без них билд не соберётся на чистой машине.

## Контракт

Новая Zastava 101 имеет отдельные кузов и колесо, а её начало координат
совпадает с узлом шасси. Исходники Blender и актуальные размеры:
[ZASTAVA_MODEL.md](../../docs/ZASTAVA_MODEL.md). Следующий абзац относится
к старым прототипам.

Кузов машины: только корпус, без колёс. Начало координат — центр по X/Z,
низ по Y = 0, вперёд −Z. Габариты: ≤ 1.66 × 4.05 м, высота ≤ 1.0 м.

Проп: начало координат на земле, вперёд −Z. Коллизии не нужны — их ставит код.

Если файла нет, игра строит процедурную заглушку: `ModelLibrary` вернёт `null`,
и всё продолжит работать.

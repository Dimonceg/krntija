# Видимые улучшения машины

Навесы готовы для Zastava 101 и ВАЗ-2106. Подключение и эффект улучшений —
за архитектором. В этой задаче код игры, характеристики и коллизии не менялись.
Имена новых улучшений сверены с уже добавленным `UpgradeCatalog`
в `core/Krntija.Core/Upgrades.cs`: `upgrade_headlights`, `upgrade_bullbar`,
`upgrade_roofrack`. Для скрытого под капотом `upgrade_engine` навеса нет.

## Подключение (архитектор, 2026-10-26)

`game/scripts/CarUpgradeVisuals.cs` — корень кузова `Body` в `Car`: кузов и навесы
его дети, навес `<spec>_<upgrade>.glb` появляется, как только улучшение
установлено (и после загрузки сейва); `lift` из JSON рессор поднимает корень,
колёса — отдельно. Новый навес для другой машины — просто положить GLB с тем же
именем, код менять не нужно. Проверка — `--check-car-upgrades` в `check.ps1`;
снимок — `--shot-car --view=quarter --upgrades=all --car=<spec>`.

## Файлы для подключения

Все файлы лежат в `game/assets/models/cars/`.

| Улучшение | Zastava 101 | ВАЗ-2106 | Треугольников на GLB |
|---|---|---|---|
| Бак | `zastava_101_upgrade_tank.glb` | `vaz_2106_upgrade_tank.glb` | 360 |
| Ящик | `zastava_101_upgrade_toolbox.glb` | `vaz_2106_upgrade_toolbox.glb` | 352 |
| Фары | `zastava_101_upgrade_headlights.glb` | `vaz_2106_upgrade_headlights.glb` | 392 |
| Кенгурятник | `zastava_101_upgrade_bullbar.glb` | `vaz_2106_upgrade_bullbar.glb` | 188 |
| Багажник | `zastava_101_upgrade_roofrack.glb` | `vaz_2106_upgrade_roofrack.glb` | 400 |
| Подвеска | `zastava_101_upgrade_springs.json` | `vaz_2106_upgrade_springs.json` | — |

Каждый JSON содержит `{ "lift": 0.04 }`: подъём визуального кузова на 4 см.
Это данные для подключения, само наличие JSON пока не меняет игру.

## Контракт

- Метры, +Y вверх, перед −Z. Начало каждого GLB — **то же начало шасси,
  что у кузова соответствующей машины**, не геометрический центр навеса.
- Добавлять навес ребёнком того же визуального корня, что и кузов:
  позиция `(0,0,0)`, вращение `(0,0,0)`, масштаб `(1,1,1)`. Не центрировать
  через AABB и не опускать его основание на землю.
- По одному мешу и одному стандартному материалу с цветами вершин на GLB.
  Сохранять рядом `.glb.import`: существующий `WorldPropImport.gd` включает
  палитру при импорте; игровых скриптов на навесах нет.
- Нет встроенных коллизий, источников света, анимаций и контроллеров.
  Свечение и дальность света задаёт подключающий код; GLB фар — только корпуса,
  линзы и крепления.
- Все улучшения независимы. Бак справа, ящик слева на крыше, у обоих собственные
  опоры. Багажник охватывает их, но не является условием появления. Стойки
  кенгурятника проходят снаружи штатных фар; его перекладины выше дополнительных
  фар и ниже указателей поворота.
- При применении `lift` поднимать кузов **вместе с навесами**, не поднимать
  меши колёс. JSON не задаёт изменение физической подвески: его реализацию
  согласует архитектор. Не менять этим смещением физический корень машины.

Стилизация: сваренные стальные профили, ржавые швы и крепления, выцветшая
эмаль, изолента на ремонтах и проводах. Все формы созданы для проекта.
Полный комплект добавляет 1692 треугольника и 5 визуальных мешей на машину;
каждый навес укладывается в ограничение 600 треугольников.

## Исходники и проверка

- `art/blender/upgrades/zastava_101_upgrades.blend`;
- `art/blender/upgrades/vaz_2106_upgrades.blend`;
- `art/blender/upgrades/geometry.json` — бюджет каждого экспорта;
- `tools/blender_car_upgrades.py` — генератор только навесов и JSON;
- `tools/car_upgrades_check.gd` — импорт, бюджеты, начало координат, материалы
  и диапазоны размещения;
- `tools/car_upgrades_review.gd` — обе машины со всеми навесами в нуле кузова,
  с визуальным подъёмом 4 см и неподнятыми колёсами.

```powershell
blender --background --python tools/blender_car_upgrades.py
godot --headless --path game --import
godot --headless --path game --script ../tools/car_upgrades_check.gd
godot --path game --rendering-method gl_compatibility --script ../tools/car_upgrades_review.gd
.\tools\check.ps1
```

Генератор использует только функции из начала `blender_zastava.py`, не
запускает сборку машины и не перезаписывает кузова, колёса или другие ассеты.
Исходники хранят детали раздельно, экспорт объединяет каждый навес в один меш.

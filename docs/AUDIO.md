# Звук

Решение пользователя 2026-10-26: мир и действия — записи **CC0**, двигатель и фон
природы — синтез кодом. Звук на правила игры не влияет: это сцена (`game/scripts`).

## Источники

- Только CC0 (без указания автора, можно продавать в Steam). CC-BY, CC-BY-SA,
  «royalty free» без CC0 — не берём.
- Каждый набор — строка в `game/assets/audio/LICENSES.md`: папка, источник (URL),
  лицензия. `check.ps1` краснеет на звуковом файле, чья папка там не указана.
- Синтез кодом — `SoundBank` (короткие звуки, циклы) и `EngineAudio` (двигатель).

## Шины громкости

`Master` → `Engine` (двигатель, шины), `World` (природа, погода, дорога),
`Sfx` (действия, шаги, удары), `Ui` (интерфейс). Раскладка —
`game/default_bus_layout.tres`; громкость каждой — ползунок в настройках
(`GameSettings`). Новый плеер обязан указать шину.

## Библиотека и API

Файлы: `game/assets/audio/<группа>/<id>_<n>.ogg` — `n` варианты одного звука
(0, 1, 2…). Группы: `foley` (действия), `steps/<поверхность>`, `impact`, `ui`,
`ambience`. Id — по смыслу (`metal_clunk`, `door_car_open`, `coins`).

```csharp
Sfx.Play("metal_clunk", position);        // 3D: случайный вариант, высота ±6 %
Sfx.Play("coins");                        // 2D (интерфейс, деньги)
Sfx.Step(SurfaceKind.Gravel, position);   // шаги по поверхности
Sfx.Ambience("crickets", intensity);      // цикл природы, 0 — выключен
```

Нет файла для id — звучит синтезированная замена, в лог одна строка
`[audio] нет звука <id>`: игра не молчит и не падает. Список id и их групп —
`SoundIds` (одно место; новые звуки — строка там).

## Бюджет

- Одновременно ≤ 24 голоса 3D; дальше 40 м короткие звуки не играются.
- `EngineAudio` и синтез в `_Process` — не больше 0,3 мс процессора на кадр
  (замер `--perf`, строка «логика» — по `PerfProbe`).
- Файлы — `.ogg`, моно для 3D, ≤ 200 КБ на вариант; фоновые циклы — до 1 МБ.

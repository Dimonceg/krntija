# Жители, животные и предметы мира

Шесть визуальных моделей в `game/assets/models/props/`:

| Файл | Для действия | Особенности |
|---|---|---|
| `resident.glb` | `talk` | Житель в коричневой куртке и кепке, рост 1,84 м |
| `dog.glb` | `dog` | Одна собака с ошейником, высота 0,94 м |
| `wolf.glb` | `wolves` | Один скелетный волк, холка 0,75 м; четыре клипа, см. [WOLF_ART.md](WOLF_ART.md) |
| `rockslide.glb` | `collapse` | Целый завал шириной 4,76 м |
| `roadblock.glb` | `exit` | Заграждение шириной 6,62 м с предупреждающей табличкой |
| `wooden_crate.glb` | `crate` | Закрытый деревянный ящик, 0,93 × 0,74 × 0,88 м |

Метры, Y вверх, лицо по −Z, начало координат на уровне стоп/основания.
Ставить на землю без старого смещения коробки по высоте. Завал и заграждение
заменяют всю группу заглушек; волк заменяет одно животное.

Каждая модель — один визуальный меш, один материал с цветами вершин.
Импорт через `WorldPropImport.gd`; настройки сохранены в `.glb.import`.
Пять моделей статические: без скелета и анимаций. Волк обновлён 26.10.2026:
скелет и клипы `idle`, `walk`, `run`, `attack`. Все модели без игровых
скриптов и встроенных коллизий.
Коллизии и поведение остаются ответственностью подключающего кода.
Житель использует собственную анатомию traveller, с изменённой одеждой и кепкой.
Сторонние ассеты не использованы.

Завал и заграждение должны удаляться вместе с узлом действия. При применении
`StaticBatcher` держать их под исключённым корнем (`SkipGroup`), иначе
объединённая геометрия останется после удаления. Ящик после открытия может
оставаться на месте: у этого ассета нет отдельной анимации крышки.

Исходники: `art/blender/life/*.blend`; статистика: `geometry.json` рядом.
Генератор: `blender --background --python tools/blender_life.py`.
Волк собирается отдельно через `tools/blender_wolf.py`; общий генератор
пропускает его, чтобы не затереть скелет и анимации статической версией.
Он использует исходник `art/blender/characters/traveller.blend` и функции
`tools/blender_world.py`, не перезаписывая исходные модели персонажа и мира.

Проверки:

```powershell
godot --headless --editor --path game --import
godot --headless --path game --script ../tools/life_art_check.gd
godot --path game --resolution 1440x900 --script ../tools/life_art_review.gd
.\tools\check.ps1
```

Проверка ассетов контролирует загрузку всех шести GLB, уровень основания,
палитру, один меш/материал и бюджет до 3200 треугольников на модель.
[Обзор в Godot](screenshots/life-props.png). Каждый объект на обзоре
масштабирован камерой отдельно: это не сравнение физических размеров.

Регистрация моделей выполняется отдельно; эта задача не меняет `game/scripts`.

Проверено 25.10.2026: проверка шести импортированных моделей — 0 ошибок;
полный `check.ps1` — «ВСЁ ЗЕЛЁНОЕ», 13 шагов и 138 тестов ядра.

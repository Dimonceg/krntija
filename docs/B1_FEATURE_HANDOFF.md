# B1: передача модели фич

Арт готов в ветке `art/zastava-modular`. Семь файлов, трансформы и снимки —
`CAR_PARTS_ART.md`. Runtime-код в этой задаче не менялся.

## Ожидаемый результат

`CarAssemblyVisual` уже ищет нужные имена. Машина должна выбирать
`zastava_101_shell.glb`, шесть панелей загружать отдельно; цельного кузова
за оболочкой быть не должно. Открытые двери показывают салон, капот —
агрегаты; после снятия агрегатов видны пустые крепления.

1. Использовать `Socket_<id>` из GLB вместо запасной раскладки по AABB.
   `Open_<id>` — конечный локальный трансформ в системе кузова. Панель
   начинается в петле: не центрировать её по AABB. Закрытая петля — точка
   установки, открытый меш — цель обводки и снятия.
2. Проверить открытие/закрытие, снятие/возврат всех панелей, реальные
   подсказки HUD, доступ под капот, обводку и коллизии открытых проёмов.
   У детали в руках петля и центр коллизии — разные точки; подбираемая
   панель не должна прыгать из-за смещённого начала.
3. Агрегаты берут позиции гнёзд из модели. Проверить установку рукой и
   закрытие капота над всеми тремя. Не двигать GLB под старые координаты.
4. Проверить сейв/загрузку разобранной машины, старт в гараже A6, сборку
   и выезд. Старые сейвы показывают состояние деталей из ядра.
5. Навесы остаются в нуле кузова. Подвеска одинаково поднимает оболочку,
   панели и навесы; колёса остаются под управлением физической подвески.

## Проверки и ответ

Арт-проверка уже прошла: `godot --headless --path game --script ../tools/car_parts_check.gd`.
Снимки сделаны настоящим импортом Godot. Это не проверка игровых действий.

Для своей интеграционной задачи: `--check-car-assembly`, `--selftest-assembly`,
`--check-car-upgrades`, `--check-house` (настоящая машина проходит ворота),
затем полный `tools/check.ps1` перед слиянием. Новые интеграционные проверки
должны проверять фактическую модель/HUD/результат действия, а не только метод.

В ответе нужны коммит, результаты проверок, один снимок машины в гараже
с открытым капотом. Дефекты арта собрать одним списком: файл/панель,
состояние, ракурс, ожидаемый результат. Имена файлов, узлов и начало координат
без согласования с артом не менять. Логика и коллизии — модели фич,
исправления геометрии — арт-модели.

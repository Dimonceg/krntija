# Передача проекта: Krntija

Документ для продолжения работы в другой сессии и на другой машине.
Читать вместе с `docs/ROADMAP.md` (что сделано), `docs/DEVLOG.md`
(почему сделано именно так) и `AGENTS.md` (правила совместной работы).

## Что это за проект

Атмосферная survival-езда по Балканам: старая машина, разбитая дорога,
заправки, блокпосты, поломки. Godot 4.7.2 (.NET) как рендер и ввод,
вся симуляция — в отдельной библиотеке на чистом C# без Godot.

Цель — Steam, кооп 2–4. Кооп сознательно отложен до конца полировки.

## Установка на новой машине

1. **.NET SDK 8** (или новее) — `dotnet --version`.
2. **Godot 4.7.2 mono** (не обычная сборка: нужна .NET-версия).
3. Переменная `DOTNET_ROOT` на папку SDK, иначе Godot не найдёт .NET:

```powershell
$env:DOTNET_ROOT = 'C:\Tools\dotnet'
```

4. Первый запуск после клонирования — импорт ассетов (папка `.godot`
   в репозиторий не попадает):

```powershell
godot --headless --path game --import
```

## Структура

```
core/Krntija.Core/     симуляция без Godot: физика машины, дорога, погода,
                       экономика, инвентарь, износ, сейвы
game/scripts/          слой Godot: Main (мир, взаимодействия), Car, Player,
                       ChaseCamera, Hud, MenuUi, RoadEvents, WorldScatter,
                       TerrainBuilder, RoadMeshBuilder, Sfx, ModelLibrary
game/assets/models/    GLB-модели машин (кузов + отдельное колесо)
tools/                 сборка, тесты, прогоны, генераторы моделей
docs/                  ROADMAP, DEVLOG, ART, ZASTAVA_MODEL, HANDOFF
```

Ключевое правило: **симуляция не знает про Godot**. Всё, что можно посчитать
без движка (расход, износ, дорога), живёт в `core` и покрыто тестами.

## Что уже работает

- Езда: raycast-подвеска, сцепление, ручник-переключатель, задний ход, износ.
- Мир: дорога по плану, террейн с обочиной, деревья (LOD-чанки), холмы,
  знаки, ЛЭП, поля, село/ферма/руины/заправка/блокпост.
- Погода: дождь, мокрое полотно, туман, время суток и закатное небо.
- События: ямы, коровы, попутчики, поломка, пост контроля, мотель (ночлег).
- HUD, журнал, меню, настройки, сейвы (F5/F9), звук синтезом.
- Выбор машины при «Новой игре»: четыре спеки с характеристиками, Esc — назад.
- Машины: Zastava 101 и Golf Mk2 — модели Blender, остальные процедурные.

## Управление

| Клавиша | Действие |
|---|---|
| W/S/A/D | газ, тормоз/задний ход, руль |
| Space | ручник (переключатель) |
| V | зажигание |
| E | сесть/выйти, заправка, лавка, шлагбаум, ночлег |
| C | вид от первого / третьего лица |
| J | журнал, внутри: ↑/↓ выбор, T замена, R изолента, F канистра |
| F5 / F9 | сохранить / загрузить |
| Shift | бег пешком |

## Команды

```powershell
# сборка и тесты
dotnet build game\Krntija.Game.csproj
dotnet run --project core\Krntija.Core.Tests

# запуск
godot --path game

# проверки без окна
godot --headless --path game -- --selftest
godot --headless --path game -- --selftest-cars
godot --headless --path game -- --smoke
godot --headless --path game -- --smoke --car=golf_2

# производительность и баланс
godot --path game -- --perf
tools\balance.ps1

# скриншоты
godot --path game -- --shot-day --at=210
godot --path game -- --shot-car --car=golf_2 --view=quarter
godot --path game -- --shot-cars
```

`tools\play.ps1` собирает и запускает игру, но **не пробрасывает аргументы** —
для флагов вызывайте Godot напрямую.

## Модели машин

- `tools/blender_zastava.py` — «стоеднаестка» (арт-агент), кузов + колесо.
- `tools/blender_golf.py` — Golf Mk2; берите его как шаблон для следующих.
- `tools/gen_cars.py`, `gen_cars2.py` — процедурные заглушки; Zastava и Golf
  они пропускают, чтобы не перезаписать Blender-модели.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background `
  --python tools\blender_golf.py
```

Геометрия колёс берётся из `CarSpec` (`WheelbaseM`, `TrackM`, `BodyLengthM`,
`BodyWidthM`, `WheelRadiusM`), поэтому новая модель встаёт без правок `Car`.

## Правила работы в репозитории

- Новая задача — новая ветка + отдельный `git worktree` (см. `AGENTS.md`).
- Общая ветка — `master`; после проверки ветка сливается в неё.
- Чужие незакоммиченные изменения не трогать и не сбрасывать.
- Пуш в удалённый репозиторий — только по отдельному разрешению.

## Грабли, на которые уже наступали

1. **UTF-8.** `Set-Content` в этой среде пишет CP1251, после чего Godot
   не грузит скрипты. Править файлы только инструментами редактора либо
   `[IO.File]::WriteAllText(path, text, UTF8 без BOM)`. Проверка:
   `tools\check-utf8.ps1`.
2. **Кэш импорта Godot.** После замены GLB удалить
   `game/.godot/imported/<имя>*` и `<имя>.glb.import`, затем `--import`,
   иначе останется старая модель.
3. **Скриншоты в `--headless`** не сохраняются — снимать с окном.
4. **События на дороге** проверяются по расстоянию, без физических триггеров:
   так нет «залипших» зон и зависимости от FPS.
5. **Первый кадр `--perf`** показывает 1 FPS — это компиляция шейдеров.

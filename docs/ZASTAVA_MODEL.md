# Zastava 101 — модель для игры

Актуальная модульная машина: `CAR_PARTS_ART.md`; проход детализации, PBR,
прозрачные стёкла и инструкции модели фич/архитектору — `ZASTAVA_DETAIL.md`.
Ниже описан исходный цельный кузов и колесо, сохранённые как основа.

Стилизованная ранняя Zastava 101: круглые фары, хромированные бамперы,
четыре боковые двери и наклонная пятая дверь. Геометрия и материалы созданы
в проекте; фотографии не используются как текстуры и не входят в ассеты.
Это игровая интерпретация, не точная реставрационная CAD-модель.

## Файлы

- `art/blender/zastava_101.blend` — редактируемые детали и модификаторы.
  Коллекция шаблона колеса скрыта в viewport, её можно включить в Outliner.
- `art/blender/zastava_101_preview.blend` — собранная машина, четыре колеса,
  студийный свет и камера; F12 делает рендер.
- `game/assets/models/cars/zastava_101.glb` — кузов, без колёс.
- `game/assets/models/cars/zastava_101_wheel.glb` — одно колесо с центром на оси.
- `tools/blender_zastava.py` — воспроизводимая сборка и экспорт обеих моделей.
- `docs/screenshots/zastava/` — ракурсы и отчёт по геометрии.

Старые `gen_cars.py` и `gen_cars2.py` пропускают `zastava_101`, чтобы не
перезаписывать новую модель. Они по-прежнему генерируют остальные кузова.

## Сборка

Из корня проекта в PowerShell:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools\blender_zastava.py
```

Для быстрой пересборки без рендеров добавьте `-- --no-render`.
Для одного ракурса: `-- --view=front`, `rear` или `side`.
Скрипт перезаписывает исходные `.blend`, экспорт и выбранные рендеры:
сохраните ручные изменения в Blender под другим именем до его запуска.

После экспорта откройте Godot Editor или выполните `godot --headless --editor
--path game --import`. Скрипт не зависит от сторонних Python-пакетов.

## Координаты и подвеска

GLB использует метры, Y вверх, перед машины направлен по −Z.
Начало кузова совпадает с началом `Car`, а не с землёй.

| Параметр | Значение |
|---|---|
| Колёсная база | 2,449 м |
| Центры осей по Z | −1,2245 и +1,2245 м |
| Центры колёс по X | −0,65 и +0,65 м |
| Радиус шины | 0,29 м |
| Центр колеса в студийном рендере по Y | −0,295 м |
| Низ кузова / крыша по Y | примерно −0,43 / +0,837 м |
| Габарит кузова с бамперами | примерно 3,95 × 1,60 м, без зеркал |

База 2,449 м взята из документа FIA; остальные величины адаптированы для
игрового ассета. В движке высоту каждого колеса задаёт raycast-подвеска.
`Car.cs` применяет эту геометрию только для нового `zastava_101`; старые модели
и варианты `--model=zastava_boxy` сохраняют прежние оси и радиус.

Визуальное колесо вращается вокруг локальной X внутри поворотного узла:
поворот руля и качение не перемешиваются. Источники света фар перенесены
к новым круглым фарам. Коллизия кузова приведена к его размерам.

Кузов имеет около 8,3 тыс. треугольников и 8 простых материалов;
колесо — около 2,5 тыс. треугольников, один общий меш на четыре экземпляра.
Точные текущие значения находятся в `geometry.json`. Это сознательное
увеличение относительно первоначального бюджета 2–5 тыс. для главной машины.
Стёкла непрозрачные стилизованные, салона и открывания дверей пока нет.

## Референсы

- [Музей Žeravica, Zastava 101 1973 года](https://muzejzeravica.org/en/item/4357):
  передняя часть, фары, решётка, окна и бамперы.
- [FIA, омологация 5784](https://historicdb.fia.com/car/zastava-101-special-1100-special-0):
  база, компоновка и вид кузова сзади. Документ относится к Special 1980 года;
  оформление передней части взято с музейного раннего автомобиля.

## Проверки

- Сборка Godot/C# без ошибок и предупреждений.
- Импорт обоих GLB и проверка изображения из игры.
- Smoke: 62,2 км/ч после 600 физических кадров, четыре колеса на земле.
- Общий `--selftest` не полностью зелёный: после загрузки RoadEvents держит
  ссылку на удалённую машину; также не прошли проверки контакта колёс у
  заправки и высоты пешехода. Эти результаты не следует считать успешным
  полным регрессионным прогоном. Задний ход, торможение и удержание ручником
  прошли. Пользовательские сохранения не затрагивались: тестовые данные
  направлены в `build/godot-user`.

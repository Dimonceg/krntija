# Golf II — Blender-модель

Пятидверная стилизованная версия CL: две круглые фары, небольшие чёрные
бамперы, характерная задняя стойка, четыре боковые двери, задний дворник,
пластиковые арки и стальные диски. Исходная геометрия создана для проекта.

## Файлы

- `game/assets/models/cars/golf_2.glb` — кузов без колёс;
- `game/assets/models/cars/golf_2_wheel.glb` — колесо с осью по X;
- `art/blender/golf_2.blend` — отдельные редактируемые детали кузова и колеса;
- `art/blender/golf_2_geometry.json` — статистика;
- `tools/blender_golf.py` — генератор;
- `tools/golf_art_check.gd`, `tools/golf_art_review.gd` — проверка и обзор.

Кузов: 4258 треугольников, 4 материала. Колесо: 1560 треугольников,
2 материала, переиспользуется четырьмя экземплярами. Палитра записана
в вершинах, импорт через существующий `WorldPropImport.gd`.
Старые `gen_cars.py` и `gen_cars2.py` пропускают Golf, чтобы не затереть арт.

## Контракт подключения

Метры, перед −Z, вверх +Y. Начало кузова — начало Car, не земля.
Положение колёс в обзорном кадре: X=±0,71, Y=−0,295, Z=±1,2375.
Радиус шины 0,30 м; начало отдельного колеса на оси вращения.
Обе стороны диска смоделированы: зеркальный масштаб не требуется.

Текущая процедурная раскладка Golf (X=±0,86, Z=±1,45, R=0,36)
не подходит к этой модели. При подключении в `CarCatalog.Golf2` нужны:

```csharp
WheelbaseM: 2.475,
TrackM: 1.42,
BodyLengthM: 3.90,
BodyWidthM: 1.665
```

`WheelRadiusM: 0.30` уже задан. Эти поля включают существующий путь
`Car.BuildBody` и загрузку отдельного колеса; новая логика в `Car` не нужна.
Длина 3,90 — геометрия основного кузова для коллайдера и существующего
расчёта положения фар; полный габарит с бамперами и номером около 4,02 м.
Ширина с зеркалами 2,04 м. Колея адаптирована для игровой подвески.
После обновления параметров проверить Golf через `--smoke --car=golf_2`,
`--selftest-cars`, посадку колёс, поворот и вид от первого лица.
Массу, мощность, передачи и баланс менять для этого ассета не требуется.

Кузов статический, стёкла непрозрачные стилизованные; салон и открывание
дверей в этот этап не входят. Коллизии задаёт существующий код машины.

## Пересборка и просмотр

```powershell
blender --background --python tools/blender_golf.py
godot --headless --editor --path game --import
godot --headless --path game --script ../tools/golf_art_check.gd
godot --path game --rendering-method gl_compatibility --script ../tools/golf_art_review.gd
.\tools\check.ps1
```

Генератор переиспользует функции начала `blender_zastava.py`, но не запускает
генерацию Zastava и не перезаписывает её модели. Обзор собирает кузов
и четыре колеса по указанным координатам, независимо от текущего CarSpec.
[Обзор в Godot](screenshots/golf-mk2.png).

# ВАЗ-2106 — Blender-модель

Четырёхдверный седан: четыре круглые фары в чёрных рамках, отдельный
багажник, тонкие хромированные бамперы с резиновыми накладками, молдинги,
форточки, вентиляция задних стоек и стальные диски с выпуклыми колпаками.
Выцветшая бежевая эмаль, грязь на порогах и небольшие очаги ржавчины.
Вся геометрия создана для проекта; фотографии в ассеты не включены.

## Файлы

- `game/assets/models/cars/vaz_2106.glb` — кузов без колёс;
- `game/assets/models/cars/vaz_2106_wheel.glb` — отдельное колесо;
- `art/blender/vaz_2106.blend` — редактируемые детали кузова и колеса;
- `art/blender/vaz_2106_geometry.json` — статистика экспорта;
- `tools/blender_vaz.py` — генератор;
- `tools/vaz_art_check.gd`, `vaz_art_review.gd`, `vaz_game_check.gd` — проверки и обзор.

Кузов: **4831 треугольник, 4 материала**. Колесо: **1440 треугольников,
3 материала**, один ресурс для четырёх экземпляров. Цвета записаны в вершинах,
импорт настроен через `WorldPropImport.gd`. Старые генераторы `gen_cars.py`
и `gen_cars2.py` пропускают этот автомобиль.

## Подключение

Метры, Y вверх, перед −Z. Начало кузова совпадает с началом `Car`;
начало колеса — на оси вращения X. Трансформации применены при экспорте.
Колесо имеет две видимые стороны и не требует отрицательного масштаба.

| Параметр | Значение |
|---|---|
| Колёсная база | 2,424 м |
| Колея в игровой модели | 1,365 м для обеих осей |
| Радиус колеса | 0,31 м — прежнее значение `CarSpec` |
| Центры колёс в обзорной сцене | X = ±0,6825; Y = −0,295; Z = ±1,212 |
| Полный габарит кузова с зеркалами и бамперами | 1,96 × 1,309 × 4,166 м (X/Y/Z) |
| `BodyLengthM` / `BodyWidthM` | 4,02 / 1,611 м |

Поля `CarCatalog.Vaz2106` включают уже существующую загрузку отдельного
колеса и размещение подвески. `BodyLengthM` описывает основной корпус:
этот размер используется существующим кодом коллайдера и фар. Полная длина
с бамперами больше. Логика `game/scripts` для подключения не менялась.
Масса, мощность, передачи, объём бака и радиус шины сохранены.

Это стилизация под действующий контракт машин: оси симметричны относительно
начала координат, свесы адаптированы, у обеих осей общая колея. У прототипа
передняя и задняя колеи различаются. Радиус шины сохранён из игры, а не
пересчитан под заводскую размерность. Модель не является инженерной копией.

Кузов статический, стёкла непрозрачные, без салона и анимации дверей.
Поворот колёс, вращение и ход подвески выполняет существующий `Car`.

## Пересборка и проверка

```powershell
blender --background --python tools/blender_vaz.py
godot --headless --path game --import
godot --headless --path game --script ../tools/vaz_art_check.gd
godot --headless --fixed-fps 60 --path game --script ../tools/vaz_game_check.gd -- --car=vaz_2106 --shot-day
godot --path game --rendering-method gl_compatibility --script ../tools/vaz_art_review.gd
godot --path game --resolution 1440x900 --rendering-method gl_compatibility --fixed-fps 60 --script ../tools/vaz_game_check.gd -- --car=vaz_2106 --shot-day --capture
godot --headless --path game -- --smoke --car=vaz_2106
.\tools\check.ps1
```

Генератор использует только функции из начала `blender_zastava.py`,
не запускает сборку Zastava и не перезаписывает другие машины.
Обзорная сцена собирает кузов и четыре колеса независимо от `CarSpec`.
Проверка игры загружает реальный `Main`: контролирует выбор кузова и колёс,
их координаты относительно арок, опору четырёх колёс, покой на ручнике
и поворот передней оси.

## Проверено

26.10.2026: импорт, бюджет геометрии и материалов, палитра, масштаб,
центр и диаметр колеса прошли `vaz_art_check.gd`. `vaz_game_check.gd`
прошёл в headless и с отрисовкой: все четыре колеса опираются на землю,
машина стоит на ручнике, поворачиваются только передние колёса.
Обзор четырёх ракурсов и снимок в игре проверены визуально.

`--smoke --car=vaz_2106`: 600 кадров, 68,6 км/ч, четыре колеса на земле,
код выхода 0. Движок сообщил о трёх оставшихся объектах при завершении.
Первый полный `check.ps1` прошёл 12 из 13 шагов: старый мир с Zastava
дважды завершился с ошибкой движка. Отдельный повтор этого сценария прошёл
с кодом 0; код завершения движка в рамках арт-задачи не менялся.
Повторный полный `check.ps1` завершился **«ВСЁ ЗЕЛЁНОЕ»**: 13 шагов,
146 тестов ядра, без повторов отдельных сценариев внутри прогона.

## 2026-10-23 — M1: журнал, ремонт, сейвы, четыре машины

### Что сделано

- **Модели машин как данные** (`CarSpec`): Zastava 101, Golf Mk2, ВАЗ-2106, ЗАЗ-968.
  Масса, мощность, бак, передаточные числа — всё в одном record'е; симулятор

- **Коробка передач** (`DriveTrain`): обороты считаются из скорости, передач
  и главной пары, автомат переключается по порогам. Пригодится для звука и
  для ручной коробки в M2.
- **Мастерская** (`VehicleService`): замена детали из инвентаря (старая
  возвращается в сумку со своим износом), ремонт изолентой (+20% за моток),
  заправка из канистры. Любая деталь — ещё и предмет с массой.
- **Журнал (J)**: список деталей с полосками состояния, инвентарь с весом,
  потребности, часы и пробег. `R` — подмотать худшую деталь, `F` — залить
  из канистры.
- **Сейвы (F5/F9)** через `SaveSerializer`; при загрузке машина пересобирается
  из сейва на том же месте.
- **`--selftest`**: headless-прогон игровых сценариев (ремонт → сейв → порча
  состояния → загрузка → проверка). Ловит поломки связки «ядро ↔ движок».
- Первый POI: заправка с навесом, колонкой и магазином. Колонка и магазин —
  с коллизией, в них можно въехать.

### Найденный баг, который стоил часа

Машина прыгала до 8 метров и не ехала. Причина — знак демпфера:

```csharp
// было: сила растёт при разжатии и падает при сжатии — подвеска качает энергию
springForce = k * compression - c * closing;
// стало
springForce = k * compression + c * closing;   // closing = -velocity·up
```

Отрицательное демпфирование превращает стойку в насос: каждый отскок выше
предыдущего. Симптом в логах — скорость скачет 2 → 8 → 0 м/с, колёса то 4, то 0.

Второй урок: спавнить машину надо в точке равновесия подвески
(`y = restLength + wheelRadius - m*g/(4k)`), иначе первый удар о землю
пробивает подвеску до кузова.

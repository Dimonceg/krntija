## M0 — Спайк (готово)

Цель: доказать, что стек работает и машина едет.

- [x] Godot 4.7.2 (.NET) + .NET SDK 8/10 установлены
- [x] Структура репозитория, `core/` + `game/`
- [x] Ядро: детали, износ, топливо, температура, инвентарь, время, сейвы
- [x] Тесты ядра (23 теста, xUnit v3)
- [x] Прототип машины на raycast-подвеске в Godot
- [x] Headless-smoke-тест: машина разгоняется > 5 м/с за 10 секунд
- [x] Git-репозиторий, первый коммит

**Критерий готовности:** `dotnet test` зелёный, `--smoke` печатает скорость > 5 м/с и выходит с кодом 0.
Факт: 42 м/с (151 км/ч), все 4 колеса на земле, код 0.

## M1 — Едет и ломается (почти готово)

Цель: 15 минут, в которые интересно играть одному.

- [x] 14 деталей с износом и влиянием на поведение
- [x] Топливо, температура, масло, аккумулятор
- [x] Инвентарь на 24 слота + предметы (канистра, ключ, изолента, еда, вода)
- [x] HUD: скорость, передача, обороты, топливо, температура, здоровье, голод, жажда
- [x] Журнал (J): состояние деталей, инвентарь, потребности, подсказки
- [x] Ремонт изолентой прямо в журнале (R)
- [x] Замена деталей: правила в ядре + 6 тестов (в UI ещё нет)
- [x] Заправка из канистры (F)
- [x] Сохранение/загрузка (F5/F9) + сценарная самопроверка `--selftest`
- [x] Четыре модели машин: Zastava 101, Golf Mk2, ВАЗ-2106, ЗАЗ-968
- [x] Коробка передач и обороты (автомат, позже — ручное переключение)
- [~] Первая дорога: 1 заправка у дороги, остальное — полигон
- [ ] Сон/отдых, смена суток с освещением
- [ ] Звук двигателя от оборотов

**Критерий:** 15 минут без вылетов; сохранился → вышел → загрузился → всё на месте.

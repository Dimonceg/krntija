## M0 — Спайк (готово)

Цель: доказать, что стек работает и машина едет.

- [x] Godot 4.7.2 (.NET) + .NET SDK 8/10 установлены
- [x] Структура репозитория, `core/` + `game/`
- [x] Ядро: детали, износ, топливо, температура, инвентарь, время, сейвы
- [x] Тесты ядра (23 теста, xUnit v3)
- [x] Прототип машины на raycast-подвеске в Godot
- [x] Headless-smoke-тест: машина разгоняется > 5 м/с за 10 секунд
- [x] Git-репозиторий, первый коммит

**Критерий готовности:** `dotnet test` зелёный, `--smoke` печатает скорость > 5 м/с и выходит с кодом 0.
Факт: 42 м/с (151 км/ч), все 4 колеса на земле, код 0.

## M1 — Едет и ломается

Цель: 15 минут, в которые интересно играть одному.

- [ ] 10–12 деталей с износом и влиянием на поведение
- [ ] Топливо, температура, масло, аккумулятор
- [ ] Инвентарь на 24 слота + предметы (канистра, ключ, изолента, еда, вода)
- [ ] HUD: скорость, топливо, температура, здоровье, голод, жажда
- [ ] Журнал (J): состояние деталей, потребности, задача
- [ ] Ремонт и замена деталей
- [ ] Сон/отдых, смена суток
- [ ] Сохранение/загрузка (F5/F9)
- [ ] Первая дорога: 1 км, 3 POI

**Критерий:** 15 минут без вылетов; сохранился → вышел → загрузился → всё на месте.

## M2 — Мир

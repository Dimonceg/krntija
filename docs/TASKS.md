## Модель фич

### Сейчас: звук (`docs/AUDIO.md`, решение пользователя 2026-10-26)

- [ ] **S2. Новый звук двигателя.** Сейчас `EngineAudio` — три «пилы» на частоте
  вспышек: гудок, а не мотор. Остаётся синтез (`AudioStreamGenerator`), шина `Engine`.
  - Вынести синтез в чистый класс без узлов (`EngineSynth.Render(Span<float>, …)`):
    его можно гонять офлайн и проверять.
  - Модель: 4 цилиндра — вспышка = короткий затухающий импульс давления, порядок
    1-3-4-2, у каждого цилиндра свой небольшой разброс силы и момента (±3 %) —
    отсюда «неровный» холостой; холостой «плавает» (±25 об/мин, ~0,7 Гц).
    Импульсы — через резонанс выхлопной трубы (полосовой 80–200 Гц) и глушитель
    (низкие частоты); на газу — шум впуска (полосовой шум 1–3 кГц ∝ газ × обороты)
    и больше «грязи»; механика — тихий стук клапанов ∝ оборотам; вой КПП ∝ скорости
    на передаче (`DriveTrain`). Сброс газа на высоких — редкие тихие хлопки.
  - Состояния: стартер (вой ~200 об/мин и такты сжатия, пока зажигание держат и
    мотор не завёлся) → «схватил» → холостой; не заводится без аккумулятора —
    только щелчок реле, без двигателя — стартер крутит вхолостую; глушение —
    обороты падают за ~0,4 с.
  - В машине с вида водителя — приглушённо (фильтр низких), снаружи — полностью.
  - Без `GD.Randf` в цикле синтеза — свой `System.Random`; без аллокаций в `_Process`;
    не больше 0,3 мс процессора на кадр.
  - Проверка `--check-engine-audio` + строка в `check.ps1`: офлайн-рендер холостого,
    разгона до отсечки и сброса — нет NaN, нет клиппинга, громкость растёт с газом;
    сохранить `user://engine_idle.wav`, `engine_rev.wav`, `engine_start.wav` — их
    послушает пользователь.
- [ ] **S3. Звуки в игре (после S1 архитектора — API `Sfx.Play`/`Step`/`Ambience`).**
